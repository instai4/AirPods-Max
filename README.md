# 🎧 Apple AirPods Max Interactive Showcase

A premium, interactive web experience designed to showcase Apple's AirPods Max. Built with native web technologies, this project focuses heavily on **"scrollytelling,"** fluid typography animations, and a seamless glassmorphic Apple aesthetic to create a truly magical user experience

## ✨ Key Features

- **Magical Scrollytelling**: Navigate through different AirPods Max color variants simply by scrolling on your mouse or swiping on your touch device. The 3D models elegantly swoop into view.
- **Cinematic Typography**: Uses Apple's signature `cubic-bezier(0.65, 0, 0.05, 1)` easing curves. As you scroll, the product details seamlessly dissolve into a blur, drift downwards, and magically snap into focus with the new details.
- **Premium Splash Screen**: A breathtaking opening sequence featuring a pulsating white Apple logo. After a brief delay, the background dissolves outwards in a soft "dusty" effect while the Apple logo swoops beautifully into its final header position.
- **Fully Responsive**: Optimized with `100svh` split-layouts and precise media queries to ensure the experience is just as flawless on a mobile phone as it is on a desktop.
- **No Dependencies**: Built entirely from scratch using pure HTML5, CSS3, and Vanilla JavaScript—no external frameworks or libraries.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and SVG embedding.
- **CSS3**: Advanced `radial-gradient` backgrounds, glassmorphism `backdrop-filter` effects, custom `@keyframes`, and complex CSS transitions.
- **Vanilla JavaScript**: State management, scroll-throttling logic, dynamic DOM updates, and FLIP (First, Last, Invert, Play) animation geometry math.


## 📱 Mobile Experience

The layout natively scales for mobile devices by splitting the screen neatly into 50/50 vertical segments. Native page scrolling is locked (`overflow: hidden`) to ensure users remain securely inside the cinematic scroll-event loop.
